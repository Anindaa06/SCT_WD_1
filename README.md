## 📌 About
A responsive landing page featuring an interactive fixed navigation menu 
built with pure HTML, CSS, and vanilla JavaScript — no frameworks required.

## ✨ Features
- Fixed navbar visible across all sections
- Navbar changes color/style on scroll
- Hover effects on menu items
- Hamburger menu for mobile screens
- Smooth scroll navigation
- Dark-themed modern UI
- Fully responsive layout

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox + Media Queries)
- Vanilla JavaScript
